# Ayodhya Deepotsav — Shubh Deepawali Living Royal Poster

An interactive, single-viewport (100vh / 100vw) celebratory digital poster built for web design competitions.

## Highlights & Features
- **Top-Left Happy Diwali Skyshot Blast**: Clicking `#btn-happy-diwali` fires a golden skyshot rocket from the bottom to the apex center with realistic acoustic propellant sound. At the apex, a 130-particle detonation reveals `jetha-happydiwali.mp4` in a golden circular frame with unmuted sound. When closed or ended, the circular frame shatters into 100+ fragments that blast outward radially.
- **Top-Right Jay Diwali Celebration Portal**: Clicking `#btn-jay-diwali` opens a royal palace jharokha playing `jetha+daya.mp4` with full dialogue and Garba music, live background sparklers, and an out-animation featuring a 6-rocket firework barrage and 50 falling 3D gold coins.
- **Sacred Ayodhya Architecture**: Nagara-style Ram Mandir Shikhara with waving saffron Dhwaja, Ram ki Paidi Ghats with Sarayu River reflections, and 150+ micro-diyas.
- **5 Tuned Harmonic Brass Bells**: Interactive temple bells tuned to C4, E4, G4, A4, and C5 with realistic physical swing animations and Web Audio API synthesis.
- **5-Stage Progressive Diya Lighting**: Dharma, Satya, Maha-Diya, Prema, Shaanti.
- **Microphone Blow / Clap Detection**: Hardware audio detection to ignite the central Maha-Diya.
- **Interactive Cracker Dock**: Cursor sparkler (Phuljhari), floating river diyas, sky lanterns, and celebratory aerial fireworks.
- **Honor Edict & PNG Export**: Judge personalization modal with dual-engine high-resolution PNG download.
- **Full Viewport Responsive**: 100vh / 100vw design optimized from 300px mobile (300w) up to 4K displays and projectors.

## How to Run
Open `index.html` in any modern web browser or double-click `START_POSTER.bat`.
